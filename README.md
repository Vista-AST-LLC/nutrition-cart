# Nutrition Cart

This program is an educational aid for students learning about nutritional careers through the use of an associated career cart. Students use a barcode scanner to scan in prepared nutrition cards and build out their meal plans for a specific day.

### This is a Node.js + Express server that serves static files, and requires both to already be installed.

To launch the server: 
+ Open the root folder ("nutrition-cart") with powershell.
+ Run "node .\app.js"
+ Go to localhost:8888 in your browser of choice.
